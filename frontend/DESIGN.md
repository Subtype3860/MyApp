# АРМ механика — цифровой интерфейс

Реализация выбранного макета №3 в ветке `refactor/integration-auth-shell`.

## Что показал анализ

- Vue 3 + Vite, маршрутизация разделов и авторизация находятся в `App.vue`.
- Содержимое `HomeView.vue` было закомментировано: после входа не было рабочего обзора.
- Боковое меню раскрывалось только при наведении, а переключатель был отключён.
- Общие стили зависели от системной светлой/тёмной темы; компоненты истории
  ремонта дополнительно использовали жёстко заданные светлые цвета.
- API `GET /api/vehicles` возвращает реестр и идентификаторы техники, но не
  оперативные статусы, текущие моточасы или календарь предстоящего ТО.

## Изменения

- Общая тёмно-синяя тема с бирюзовым акцентом в `src/styles/digital.css`.
  Тема применяется к экрану; существующие стили печати не переопределяются.
- Единый компонент бренда `BrandIdentity.vue`, обновлённый экран входа.
- Главная страница: первый экран «Техника под контролем», сводка реестра,
  поиск по модели/типу/группе/номерам/VIN, страницы по 8 записей,
  переходы к доступным пользователю рабочим разделам.
- Только реальные данные API. Сводка содержит количество техники, моделей,
  типов и групп. Статусы и показатели из визуального макета не имитируются.
  Предстоящий календарь ТО требует отдельного API и здесь не добавлен.
- Запрос реестра не выполняется без права `menu.vehicles`. Ссылки на создание
  заявки и ремонт учитывают права родительского меню и подраздела.
- Есть состояния загрузки, пустого реестра, пустого поиска и ошибки с повтором.
  Запрос отменяется при уходе со страницы.
- На ПК меню раскрывается кнопкой; на ширине до 760 px — выдвижная панель.
  Поддерживаются Escape, удержание фокуса, возврат фокуса к кнопке открытия,
  закрытие по фону/выбору раздела, блокировка фоновой прокрутки и переключение
  на десктоп при изменении размера окна.
- Показатели перестраиваются в сетку 2 × 2. Реестр превращается в карточки.
  Таблицы существующих рабочих разделов сохраняют свои действия и локальную
  прокрутку там, где карточное представление не предусмотрено.
- История ремонтов и вложенные карточки используют общие цвета темы.

## Проверка

```bash
cd frontend
npm ci
npm run build
npx playwright install chromium --only-shell
npm run test:e2e
```

Браузерные тесты используют контролируемые ответы API, без подключения к
рабочей базе и без изменения пользовательских данных. Проверяются размеры
320, 390, 768 и 1440 px, поиск/пагинация, управление мобильным меню с клавиатуры,
смена размера экрана, ограниченные права, повтор после ошибки и истечение сессии.
Скриншоты тестовых данных создаются в `test-results/` и не коммитятся.

Это проверка интерфейса, а не интеграционный тест с работающим C# API.
Предупреждение Vite о размере PDF/fontkit chunk остаётся: изменение PDF-модуля
не входит в задачу дизайна.
