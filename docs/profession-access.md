# Разделы и блоки страниц по профессиям

Администратор открывает «Настройки → Профессии → Разделы и блоки страниц для профессий». Кнопка «Настроить» загружает текущие настройки одной профессии. Дополнительные отметки профессий позволяют применить тот же набор ко всей выбранной группе. Отдельный именованный справочник групп не создаётся.

Доступны все разделы существующего каталога прав. Для блоков страниц сейчас поддержан отчёт за смену: ремонт, проведённые ТО, вспомогательные работы, исполнители, фото и видео. Видимость одинаковая в предпросмотре и PDF. Скрытые медиа не загружаются и ссылки для них не формируются. Настройка блоков управляет представлением отчёта, а не секретностью полей общего API истории ремонта; серверные права на операции остаются отдельными.

Настроенный набор разделов профессии заменяет индивидуальный набор пользователя; пустой набор закрывает все ограниченные разделы. Выбранный подраздел включает обязательные родительские меню. Главная и профиль остаются общими. При включении «Использовать индивидуальные разделы пользователей» сохраняются личные права и прежнее автоматическое право механика на моточасы. При явном наборе профессии моточасы включаются явно. Администраторы всегда сохраняют полный доступ.

Кнопка «Вернуть индивидуальные разделы и все блоки» сбрасывает ограничения выбранных профессий. Индивидуальные настройки пользователей не удаляются. Настройки автоматически распространяются на новых сотрудников этой профессии.

API `GET/PUT /api/admin/profession-access` доступен только роли administrator. Изменение группы атомарно; каждая профессия имеет ревизию для защиты от перезаписи другим администратором. Одновременно меняются метки сессий затронутых пользователей, кроме администраторов. Сотрудникам требуется повторный вход; старый токен больше не проходит проверку. Сохранение без изменений сессии не завершает.

DatabaseInitializer добавляет в professions nullable permission_override, hidden_page_blocks и access_revision. Значения по умолчанию сохраняют прежнее поведение. Эти три колонки применены к локально подключённой базе; действующие настройки профессий не изменялись.
