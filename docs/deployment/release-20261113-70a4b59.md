# Release 20261113-70a4b59

Published to https://boora.ru/ on 2026-11-13 (Asia/Sakhalin). Коммит `70a4b59`
(игра «1000», фронтенд).

## Сохранение офлайн-партии

- Состояние партии против ботов автоматически пишется в `localStorage`
  (`thousand.save`, версия 1) после каждой раздачи, каждого хода и при выходе в меню.
- В главном меню появился пункт **«Продолжить партию»** — он виден, только если есть
  сохранение. Нажатие восстанавливает игру с тем же счётом, рукой и фазой.
- Сохранение удаляется при завершении партии и при старте новой.
- Для точного продолжения сохраняется и состояние генератора случайных чисел
  (`createRng` получил `getState`/`setState`, экспортирован из движка), поэтому
  дальнейшие раздачи совпадают с прерванной партией.
- Онлайн-партии не сохраняются: там состояние авторитетно на сервере.

Обновлены `js/main.js`, `js/ui.js`, `js/engine.js`, `index.html` — и в `Games\1000`,
и в `frontend/public/games/1000` (копии синхронизированы).
