# Release 20261109-f01bc7d

Published to https://boora.ru/ on 2026-11-09 (Asia/Sakhalin). Commit `f01bc7d`,
branch `refactor/integration-deepseek` (frontend; API build `20261109-945cb39` unchanged).

## Проблема

После очередного релиза браузер с открытой вкладкой падал с
`Failed to fetch dynamically imported module: …/assets/es-BKz3NGnE.js` —
вкладка ссылалась на файл из новой сборки, которого на сервере ещё не было
(деплой распаковывал архив прямо в работающий каталог), а `index.html` кешировался
браузером без явных заголовков.

## Changes

- `index.html` отдаётся с `Cache-Control: no-store, must-revalidate` (nginx,
  `location = /index.html`); хешированные файлы в `/assets` по-прежнему `immutable`.
- Клиент перехватывает `vite:preloadError` и один раз перезагружает страницу,
  подхватывая новый `index.html` вместо ошибки.
- Деплой фронтенда теперь безопасный: новые ассеты копируются с сохранением старых,
  `index.html` обновляется последним, после копирования выполняется
  `restorecon -R` (без него SELinux блокировал чтение и сайт отдавал 403).

## Verification
