## Таблица «Работники»: телефоны в одной колонке

- В «Таблицы → Работники» дублирующиеся телефонные колонки из импорта CSV объединяются
  в одну колонку «PhoneNumber»; значения склеиваются через запятую, повторы убираются.
- Проверка на проде: колонки LastName, FirstName, Patronymic, PhoneNumber, Profession,
  FullName, Роспись; значения телефона — один номер без дублей.
