## Changes

- Цикл «Цикл 350–4000» пересмотрен: **каждый интервал между ТО равен 350 м/ч**
  (раньше каждый третий шаг был 300 м/ч, чтобы попадать в номинальные отметки
  1000/2000/4000). Теперь отметки цикла растут ровно на 350:
  350, 700, 1050, 1400, 1750, 2100, 2450, 2800, 3150, 3500, 3850, 4200 — названия
  ТО-350/700/1000… остаются номинальными.
- Обкаточное ТО по-прежнему 150 м/ч (отдельная запись, не входит в цикл), после него
  отсчёт идёт по 350 м/ч.
- Обновлены тесты планировщика.

## Important

- Существующие графики в базе не переписывались: у них в снимке сохранены прежние
  интервалы (с 300). Чтобы применить новый цикл, нужно нажать «Заполнить цикл:
  Цикл 350–4000» и сохранить график по каждой машине — либо выполнить миграцию
  снимков централизованно (по согласованию).
- В присланной последовательности есть расхождение: после 2950 следующий шаг
  +350 даёт 3300, а не 3330 (далее 3650/4000/4350 вместо 3680/4030/4380).
  Требует подтверждения, какая отметка верна.
