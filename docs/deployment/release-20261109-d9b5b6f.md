# Release 20261109-d9b5b6f

Published to https://boora.ru/ on 2026-11-09 (Asia/Sakhalin). Commit `d9b5b6f`,
branch `refactor/integration-deepseek` (API and frontend).

## Причина обращения

При добавлении медиа в карту ТО приложение зависало, после обновления страницы
пользователь оказывался на экране входа.

## Изменения

- Фото карты ТО перед отправкой пережимаются в WebP (`createImageBitmap` + canvas,
  большая сторона до 1600 px, качество 0.8) — вместо оригинала на 3–8 МБ уходит
  файл 150–400 КБ. Если браузер не может декодировать файл (например, HEIC),
  отправляется оригинал.
- Загрузка медиа ограничена таймаутом 180 с, остальные запросы карты — 60 с:
  зависшее соединение больше не оставляет форму в состоянии «Сохранение».
- Ответы без тела больше не приводят к `Unexpected end of JSON input`: тело
  читается безопасно, показывается понятное сообщение.
- Сервер принимает `image/webp` для медиа карты (проверка по сигнатуре RIFF/WEBP),
  сообщения об ошибках обновлены.
- Прочие исправления состояния: по завершении ошибки `busy` сбрасывается, поле
  выбора файла очищается.
