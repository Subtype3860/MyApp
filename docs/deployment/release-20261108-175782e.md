# Release 20261108-175782e

Published to https://boora.ru/ on 2026-11-08 (Asia/Sakhalin). Commit `175782e`,
branch `refactor/integration-deepseek`.

## Changes

- Из этапов ремонта убран статус «Ожидает запчасти»; в форме остались «В работе» и
  «Выполнена». Существующие этапы `awaiting_parts` переведены в `faulty`
  («Неисправна»), ограничение `ck_vehicle_works_repair_status` пересоздано только
  для `repaired`/`faulty`. Старый Android-клиент может прислать `awaiting_parts` —
  сервер приводит его к `faulty`.
- Заявка на закупку ЗЧ прикрепляется к технике: `vehicle_parts_requests.vehicle_id`
  (FK на `number_car`), `defect_id` стал необязательным, существующие заявки
  привязаны к технике через свою неисправность. Новый эндпоинт
  `POST /api/vehicles/{vehicleId}/parts-requests`; редактирование и удаление —
  через существующие `PUT`/`DELETE /api/vehicles/parts-requests/{id}`.
- В разделе «Заявка на закупку ЗЧ» одна строка на технику: добавить, изменить,
  удалить, отметить выполнение.
- «ОЗЧ» в «Выходе ГТО» определяется открытой заявкой на закупку (без даты выполнения).
