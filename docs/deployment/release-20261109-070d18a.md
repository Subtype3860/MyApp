# Release 20261109-070d18a

Published to https://boora.ru/ on 2026-11-09 (Asia/Sakhalin). Commit `070d18a`,

## Причина зависания карт ТО

`GET /{vehicleId}/cards` и ответы `PUT`/действий возвращали карту вместе с полной
историей изменений (`audit`). История хранит снимок данных на каждую версию:
у карты `11eeaf41…` при 35 ревизиях это **299 КБ** — каждый список карт и каждое
автосохранение скачивали около 300 КБ, а история росла на ~8,5 КБ за сохранение.
На мобильном интернете это выглядело как зависание, а поле даты блокировалось
флагом `busy` на время запроса.

## Changes

- Список карт и ответы сохранения больше не содержат `audit`: только счётчик
  `auditCount`. Полная карта с историей отдаётся новым `GET /api/maintenance-plans/cards/{id}`.
- В интерфейсе история изменений загружается по кнопке «История изменений (N)»,
  а не вместе с картой.
- История ограничена последними 40 записями при каждом сохранении.
- Автосохранение больше не блокирует форму: черновик уходит на сервер в фоне,
  поле даты и чек-листы остаются доступными; при наложении сохранений запрос
  повторяется, а не теряется.
- Для старых вкладок с закешированным фронтендом в ответе сохранён `audit: []`,
  поэтому устаревший клиент не падает.
