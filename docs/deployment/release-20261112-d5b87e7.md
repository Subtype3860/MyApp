## nginx

Для `location ^~ /games/` задана отдельная CSP (остальные заголовки безопасности
сохранены):

- `script-src 'self' blob: 'wasm-unsafe-eval'` — Unity запускает загрузчик из `blob:`
  и компилирует WebAssembly;
- `connect-src 'self' blob: data:`, `worker-src 'self' blob:` — потоки и данные игры.

Резервная копия конфигурации: `/etc/nginx/conf.d/myapp.conf.backup-games-csp-20261112`.

## Замечание по сборке игры

В консоли Unity: `Can't add component because class 'BoxCollider'/'SphereCollider'
doesn't exist!` — в билде отключён модуль физики (или включён managed stripping).
Если в игре важны столкновения, сборку нужно пересобрать с `Physics` в Project Settings →
Player → Publishing Settings (Managed Stripping Level ниже), после чего повторить
публикацию: файлы кладутся в `frontend/public/games/fortpost`.
