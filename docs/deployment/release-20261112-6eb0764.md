## Права доступа к играм

- В каталог разрешений добавлена группа **«Игры»**:
  - `menu.games` — доступ к разделу «Игры»;
  - `games.mechanic` — «Смена»;
  - `games.tanks` — «Танки 3D» (существующее право, теперь в группе);
  - `games.fortpost` — «Форпост».
- Меню «Игры» скрывается без права `menu.games`; отдельные игры показываются по своим
  правам. Если выдано только `menu.games` (без отдельных игр), доступны все три игры.
  Администратор видит раздел всегда.
- Действующим профессиям право `menu.games` выдано миграцией, чтобы игры не пропали:
  обновлено 27 записей, резервная копия `professions_backup_20261112`.
  Отозвать доступ можно в «Настройки → Права по профессиям → Игры».
