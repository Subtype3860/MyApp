## Changes

- При проведении ТО расчёт ведётся от **даты и времени, указанных в карте**: принимается
  время окончания работ (`finishedAt`), если оно не заполнено — возврата в работу
  (`releasedAt`), затем начала работ (`startedAt`).
- Базовые моточаса для завершения берутся только из показаний, снятых **до этого
  момента**: `reading_date < дата` либо `reading_date = дата` и `reading_time <= время`
  карты. Показания, загруженные позже обслуживания за ту же дату, в базу цикла не
  попадают.
- В плане ТО сохраняется время последнего обслуживания (`lastTime`), в сводке оно
  показывается рядом с датой.
- Время входит в отпечаток операции завершения (защита от дублей).
