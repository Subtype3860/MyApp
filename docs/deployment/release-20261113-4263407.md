## Выбор карт при сносе

На сносе (после прикупа) при выборе третьей карты игра показывала сообщение
«Снести можно ровно две карты» и не меняла выбор — приходилось сначала снимать
отметку с одной из выбранных карт.

Исправлено в `js/ui.js`:

- третья карта **заменяет самую раннюю** из выбранных, сообщение больше не появляется;
- повторный клик по выбранной карте по-прежнему снимает выбор;
- перед выбором список очищается от карт, которых уже нет на руке (после смены
  состояния или новой раздачи), чтобы «Отдать» не отправлял устаревшие карты.

Обновлены `Games\1000\js\ui.js` и `frontend/public/games/1000/js/ui.js`.
Серверная часть (движок, комнаты) не менялась.
