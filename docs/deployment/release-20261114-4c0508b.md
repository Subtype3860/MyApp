## Карточки ТО: разделы вместо операций

Новая концепция: по операциям отчёт не ведётся — только по разделам (ДВС, Шасси и т. д.).

- В карточке ТО вместо строк операций — блоки разделов. В блоке:
  - **медиа раздела** (фото/видео): загрузка и просмотр, ключ раздела `section:<Имя>`;
  - **участники**: кнопка «Я участвовал» добавляет работника со статусом «ожидает»;
  - механик **подтверждает** или отклоняет участие (бейджи «ожидает»/«подтверждён»/«отклонён»).
- Раздел «Заключительный контроль» не выводится.
- Отчёт по ТО (сменный отчёт): список разделов, медиа сгруппировано по разделу,
  под фото — **подтверждённые** участники; в PDF то же.

## API

- `card.data.sections` — разделы с участниками (`CardSection`, `CardParticipant`);
- `POST /api/maintenance-plans/cards/{id}/participation` — текущий пользователь отмечается
  участником раздела (черновик);
- `POST /api/maintenance-plans/cards/{id}/participation/decision` — подтверждение/отклонение
  механиком;
- `GET /api/maintenance-plans/shift-report` возвращает `sections` с участниками и фото.
