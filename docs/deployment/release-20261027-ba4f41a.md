## Changes

- Cache immutable tank arena geometry in GPU memory; reuse dynamic typed buffers, simplify pickup rings and skip offscreen dynamic objects.
- Interpolate remote movement and predict the local tank's motion before the server reply, reconciling unacknowledged input against server snapshots.
- Add server `ackSeq` and `spawnId`, reject replayed input sequences, and retain authoritative movement speed, health, damage, pickups and permissions.
- Send keyboard changes immediately; avoid rebuilding unchanged HUD elements and redrawing idle scenes at the monitor's full refresh rate.
- [Performance measurements and limits](../games/tanks-performance.md).
