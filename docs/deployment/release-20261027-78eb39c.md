## Changes

- Games menu with Mechanic Simulator «Смена» and multiplayer Tanks «Броня»; game pages account for expanded/collapsed navigation and mobile layouts.
- Mechanic diagnosis, parts, repair timing, upgrades and browser-local progress.
- Server-authoritative PvP arena for up to eight registered users, live admission checks, pickups, damage, respawn and leaderboard.
- Administrator admission through the existing user editor: `games.tanks`. Ordinary new/existing users do not receive the new permission automatically; administrators retain their normal all-permissions behavior. No production user permissions were changed during deployment.
- Shared 128×128 map with 40 obstacles packaged with both server and frontend.
- nginx WebSocket upgrade route and revalidation for game files.
- Start button is disabled until game initialization completes, preventing a lost early click on slower connections.
