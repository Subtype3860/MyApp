## Ошибка выбора карт в игре «1000»

Причина: движок требовал играть козырем всегда, когда нет карты заходной масти, —
даже если козырь **уже лежит на столе**. По правилам игры («Перебивать козырем не
обязательно, если козырь уже на столе») в такой ситуации можно сбросить любую карту.
Из-за этого периодически появлялось сообщение «Этой картой ходить нельзя», когда игрок
пытался сбросить некозырную карту после чужого козыря.

Исправлено в `js/engine.js`:

```js
const trumpOnTable = state.trick.some((t) => suitOf(t.card) === state.trump);
if (!trumpOnTable) { // иначе козырь перебивать не обязано
  const trumps = hand.filter((c) => suitOf(c) === state.trump);
  if (trumps.length) return trumps;
}
```

Обновлены три копии движка:

- `Games\1000\js\engine.js` (исходная игра на диске);
- `frontend/public/games/1000/js/engine.js` (раздаётся приложением);
- `/opt/myapp/games/1000-server/js/engine.js` (авторитетный онлайн-сервер, сервис
  `myapp-1000` перезапущен).
