## Причина

Поля «Остановка техники / Начало работ / Окончание работ / Возврат в работу» —
нативные `datetime-local`. Каждое промежуточное изменение в выборе даты вызывало
`changed()` → автосохранение, а ответ сервера **подменял весь объект данных формы**.
Из-за этого нативный выборщик терял значение и фокус при каждом шаге — выглядело как
зависание при нажатии на «Окончание работ».

## Changes

- Ввод в поле времени теперь только запоминается в локальном состоянии (`syncTime`),
  без запуска сохранения. Сохранение — по подтверждению выбора (`change`) или
  потере фокуса (`blur`).
- Автосохранение больше не заменяет данные формы после ответа: обновляются только
  ревизия и счётчик истории. Полная синхронизация остаётся для явных действий
  (отправка, принятие).
- Поле «Водитель / машинист» получило `autocomplete="off"`, чтобы браузер не
  подставлял туда дату.
