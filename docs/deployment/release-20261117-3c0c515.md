## Один материал на разную технику в одной накладной

В списке выбранных компонентов:

- появилась колонка **«Техника»** — у каждой строки свой номер машины;
- кнопка **«Ещё на технику»** дублирует строку, чтобы выписать тот же материал
  на другую машину (в документе это отдельная строка со своим номером техники);
- поле «Номер техники» в шапке работает как раньше (один номер или несколько через «;»).

Правило: если техника заполнена по строкам, она должна быть указана у каждой строки
(иначе подставляется общий номер из шапки).

На сервере добавлена проверка: суммарное количество по одному наименованию (несколько
строк на разные машины) не может превышать остаток — иначе ошибка с указанием материала.
