## Ошибка «Не удалось создать публичную ссылку на вложение»

Причина: эндпоинт `POST /api/maintenance-plans/cards/{id}/media-links` возвращает
элементы вида `{ id, url }` (`CardMediaLink(Guid Id, string Url)`), а клиент искал
поле `photoId`. Ссылка складывалась под ключом `image:undefined`, и при построении PDF
любое фото карты ТО оставалось без адреса — отчёт не собирался.

Исправлено: ключ ссылки берётся из `id` (с запасным `photoId` для совместимости).
Тест в сменном отчёте переведён на реальную форму ответа и проверяет PDF с фото ТО.
