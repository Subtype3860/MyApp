## Changes

- Новый раздел «Таблицы → SANY: запчасти»: подключение к порталу SIS по логину и
  паролю с капчей, которую вводит человек.
- Сервер хранит подключение изолированно (собственные cookies), пароль живёт только
  до ввода капчи и стирается после входа, токен действует до истечения (по умолчанию
  8 часов, `Sany:TokenHours`).
- Шлюз разрешает только разделы портала из белого списка (поиск техники, BOM, мануалы,
  список языков), запросы выполняются от учётной записи пользователя.
- Экран показывает ответ портала как есть — на этом шаге проверяем реальные контракты
  запросов и ответов SIS.

## Endpoints

- `POST /api/sany/session` `{account, password}` → `{sessionId, captchaImage, contentType, expiresAt}`.
- `POST /api/sany/session/{id}/login` `{captchaCode}` → `{connected, expiresAt}`.
- `GET /api/sany/session/{id}` — состояние.
- `DELETE /api/sany/session/{id}` — отключение.
- `POST /api/sany/session/{id}/query` `{path, body}` — прокси к разрешённому разделу.

Ограничения: 5 попыток капчи на подключение, сессия ожидания 15 минут, TTL токена
1–24 часа.
