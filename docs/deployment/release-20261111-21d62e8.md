## Серверная конвертация фото в WebP (вариант B)

- На сервер установлены `libheif-tools` (`heif-convert`) и `libwebp-tools` (`cwebp`).
- Добавлен `MediaImageNormalizer` (Infrastructure): определяет формат по сигнатуре,
  приводит изображения карт ТО к WebP:
  - JPEG/PNG → `cwebp -q 80 -m 4`;
  - HEIC/HEIF → `heif-convert -q 90` → JPEG → `cwebp`;
  - WebP сохраняется как есть;
  - видео и неизвестные форматы не трогаются.
- Ограничения и защита: исходник до 25 МБ, результат до 8 МБ (далее проверка 4 МБ для
  фото карты), таймаут утилит 20 с, временные файлы в `%TEMP%/atlas-media` удаляются,
  процессы запускаются без shell-подстановок.
- Если утилит нет (локальная Windows-среда), сервер сохраняет исходный файл — тесты и
  разработка не ломаются.
- HEIC распознаётся в `MaintenanceCardMedia` независимо от лимита фото: снимок iPhone
  может быть больше 4 МБ, его уменьшает сервер.
- Сообщения об ошибках обновлены: «Допустимы фото JPEG/PNG/WebP/HEIC…».
