# Карточки ТО: разделы вместо операций (концепция 2026-11-14)

## Решение

- Ведём только **разделы** карты (ДВС, Шасси, Гидравлика…), без отчёта по каждой операции.
- Работник не отмечает операции. Вместо этого у раздела есть:
  - **медиа** (фото/видео), привязанное к разделу;
  - кнопка **«Я участвовал»** — участник попадает в список со статусом `pending`;
  - механик подтверждает участие (`approved`) или отклоняет.
- Отчёт по ТО показывает разделы, их фото и подтверждённых участников.

## Данные

`card.data.sections: [{ section, participants: [{ userId, name, position, status, approvedBy, approvedAt }] }]`

Фото остаются в `maintenance_card_photos`; `OperationId` используется как ключ раздела:
`section:<Имя раздела>` — схема БД не меняется.

Шаблон ТО сохраняет операции (для истории и совместимости), но карточка группирует их
по `section` и показывает только разделы.

## API

- `POST cards/{id}/participation` `{ section }` — текущий пользователь отмечается участником
  (draft, любой, кому доступна карта).
- `POST cards/{id}/participation/{userId}/approve|reject` — только механик/менеджер карт.
- Загрузка медиа: существующий `POST cards/{id}/photos?operationId=section:<...>`.

## UI

`MaintenanceCards.vue`: блок раздела — заголовок, кнопка «Я участвовал», список участников
(с бейджем «подтверждён»/«ожидает»), медиа раздела (превью, загрузка, удаление).
Механик видит кнопки подтверждения.

Отчёт (`maintenanceReportGroups`): группы фото по разделу, подпись — подтверждённые участники.
