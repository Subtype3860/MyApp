# Моточасы

В меню «Транспорт → Моточасы» доступны компактный ручной ввод и импорт через модальное окно. Дата показаний общая; самосвалы имеют поля ДВС № 1 и № 2, остальные машины — одно поле. Показания сохраняются отдельно по двигателям и используются в «Выходе ГТО». Значения при замене ДВС остаются отдельными данными.

Импорт принимает CSV UTF-8 и XLSX до 5 МБ. Колонки: `garage_number`, `model`, `engine_1`, `engine_2`. Например:

```csv
garage_number;model;engine_1;engine_2
901;SANY SET 150S;875;852
94;SANY SY1250H;20511;
```

Техника определяется по точному сочетанию гаражного номера и модели без учёта регистра. Пустые ячейки двух колонок не изменяют показания. Альтернативный формат трёх колонок допускает `875/852` для самосвала, одно значение для техники с одним ДВС. Единственное число для самосвала отклоняется, чтобы не присвоить показания неверному двигателю. Старые двухколоночные XLSX с известными обозначениями техники читаются с теми же правилами.

Импорт пишет показания на выбранную дату; повторный импорт обновляет показания этого двигателя за этот день. Окно показывает число принятых показаний и ошибки по строкам. Отрицательные значения и второй ДВС у машины с одним двигателем отклоняются. Дубли конкретного ДВС пропускаются. Шаблон CSV можно скачать в окне импорта.
