# «Смена»: браузерный симулятор механика

Локальный адрес: http://localhost:5150/games/mechanic/index.html

Запуск: `npm run dev` из `frontend`. Игра находится в `frontend/public/games/mechanic`, попадает в сборку Vite как самостоятельная страница. Для локального Vite нужно указывать `index.html` в адресе. Публикация ещё не выполнена.

## Как играть

1. Принять заказ и прочитать симптомы.
2. Проверить одну из четырёх систем. Каждая проверка занимает 15 игровых минут.
3. Купить найденную деталь за деньги мастерской (10 минут).
4. Трижды остановить указатель в зелёной зоне кнопкой или пробелом. Каждая попытка занимает 10 минут.
5. Выдать машину и получить оплату. Сдача до 90 минут включительно даёт дополнительные 120 ₽.

За пять заказов выплачивается однократная премия 1 000 ₽. Между заказами доступно улучшение инструмента за 700 ₽, расширяющее зелёную зону. После первой смены можно продолжать игру; шесть неисправностей повторяются по кругу. Репутация растёт за выполненные заказы, соблюдение срока и ремонт без промахов.

Начальная касса — 600 ₽. Время расходуется только на действия. Промах не уничтожает деталь: теряется только время и возможность премии. Основная оплата остаётся доступной после истечения срока. Это условная игровая модель, не инструкция по ремонту реальной техники.

Сохранение: localStorage, ключ `smena.mechanic.v1`; текущая работа, деньги, улучшение, премия и журнал. Подтверждённая «Новая игра» сбрасывает только этот ключ. При недоступности хранилища игра работает до закрытия вкладки и показывает предупреждение. Между вкладками состояние обновляется перезагрузкой. Пользовательские данные Atlas, API и внешние сервисы не используются. Звук синтезируется локально и изначально отключён.

## Проверки

`PLAYWRIGHT_CHANNEL=msedge npx playwright test tests/mechanic-game.spec.js` (в PowerShell задайте переменную через `$env:PLAYWRIGHT_CHANNEL='msedge'`).

Три браузерных теста: прохождение пяти заказов и экономика; ошибочная диагностика, промах, восстановление заказа и подтверждение сброса; мобильная ширина и повреждённое сохранение. Время мини-игры контролируется Playwright Clock. Проверены скриншоты 1440 и 390 px. Производственная сборка проходит; существующее предупреждение о размерах чанков основного приложения сохраняется.
